# AI and automation

I use OpenAI Codex for a second pass on repository reviews, documentation, small code changes, and checking test results. I read the proposed changes and decide what goes into the projects.

Dependabot opens dependency update pull requests. GitHub Actions runs configured checks. Those are automation tools, not generative AI. A passing check only covers the behaviour that the check actually tests.

SentriCode has an optional AI explanation feature for a selected, redacted finding. The scanner itself works without an AI key, and an explanation cannot suppress a finding or change a repository.

I do not use generated screenshots or invented project metrics to present the work. The repositories and their commit history show what is implemented; the portfolio's interactive diagrams use sample states and say so on the page.
